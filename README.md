# JAH Universal Calculator

The sixth JAH site. Solves anything, paradox immune, powered by the JAH deterministic system.

**Live:** https://justinahiggins614-cmyk.github.io/jah-calculator/

## What it does

- **Basic** — hand-written expression parser (never `eval()`), step-by-step breakdown, memory keys
- **Scientific** — trig (deg/rad), logs, powers, roots, factorial, constants (π e φ τ), quadratic + cubic solver, unit converter (length, mass, temperature, data, time)
- **Ask Anything** — type math to compute it, or ask any question for the full JAH ten-lens deterministic analysis (deterministic, probabilistic, geometric, hash, neural, evolutionary, fuzzy, swarm, decision-tree, cellular-automata + hybrid fusion verdict)
- **Paradox Check** — paradox immune: detects liar, barber, Russell, sorites, unexpected hanging, omnipotence, grandfather, Ship of Theseus, Zeno patterns; classifies, contains at object level (UNDECIDABLE), resolves one level up. Never throws, never loops.
- **Project** — paste a number series, get linear + exponential least-squares fits, R², forecast chart + table
- **Simulate** — Game of Life, Monte Carlo π, dice probability lab, random walk (canvas, run/pause/reset)
- **Lab** — virtual experiment bench: pendulum, projectile motion, Ohm's law, ideal gas. Sliders, live readouts, lab notebook, CSV export.

Every tab: 🔊 Read aloud (tiered TTS: speechSynthesis female voice → ResponsiveVoice → Google TTS), ⧉ Copy result, ⤓ Download .txt, and "Send this to…" cross-links (The Signature Dictionary, JAH Wiki, Spec Catalog).
